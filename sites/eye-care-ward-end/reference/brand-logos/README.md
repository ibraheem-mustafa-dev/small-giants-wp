## Source

All files pulled from JP Opticians UK (`https://jpopticians.com/jp_uk`), which serves the
raw (un-resized) copy of each brand-strip logo at:

```
https://jpopticians.com/media/logos/brand-logos/hyva-spex4less/small/<slug>.jpg
```

(A `webp`-converted, same-resolution copy of the same file is also served at
`https://jpopticians.com/media/mf_webp/jpg/media/logos/brand-logos/hyva-spex4less/small/<slug>.webp`
via the site's on-the-fly image-conversion layer — not used here since the raw JPG/PNG is
identical resolution and simpler to archive.)

**No SVGs exist for any of these logos on the site.** Every asset is a small raster strip
image (this is the size the theme uses to show a brand's logo on its product tiles/pages),
not a scalable vector — see "Anything odd" below.

## Anything odd

1. **Every logo is small and low-resolution** (roughly 60–180px wide, 12–45px tall) — these are website UI strip logos sized for a product-tile carousel, not press-kit assets. Several (Chloe, Montblanc, Ray-Ban, Swarovski) are identically 65×29px, suggesting a shared placeholder-ish crop rather than brand-supplied art. Expect visible pixelation if scaled up much beyond their native size in a design draft.
2. **No SVGs anywhere on the site for these logos** — despite the task's preference for SVG, JP Opticians only serves raster JPG/PNG at this one small size. There is no larger or vector source on the site to fall back to.
3. **Dsquared2's asset is a PNG despite living at a `.jpg` URL** — the server ignores the extension and serves whatever format the file actually is; saved here with the correct `.png` extension.
4. **Several logos are wordmarks/text rendered as an image**, not distinctive marks — Cat, DKNY, Farah, Marc Jacobs, MaxMara, Michael Kors, Polaroid, Radley, Ralph Lauren, Tiffany are essentially typeset brand names as a small flat image, no logotype styling beyond the font.
5. **No watermarking** was found on any downloaded file.
6. **Inconsistent sizing/aspect ratio** across the set (heights range from 12px to 45px) — expect to need per-logo padding/scaling if laying them out in a uniform grid.
