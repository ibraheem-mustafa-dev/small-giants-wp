# <Project name>: design handoff

A guide for the people and agents who build this design. The drafts' code is the source of truth; this README explains
it and records what the code cannot say. Write "None" under a heading that has nothing to say. Never map the design to
WordPress or SGS blocks: the builders choose blocks from the code.

## Overview
What the site is for, who it serves, and the feel the design aims at.

## Files
Each draft and script in this folder and what it is (page, shared component, form, data).

## Routes
Every page or screen, the route or file it lives at, and how a visitor reaches it.

## Global layout
Header, footer, navigation, drawers and anything else on every page.

## Pages
One short paragraph per page: its sections in order and anything unusual about them.

## Forms
Each form: its steps, fields, conditions and what happens on submit.

## Animations and interactions
The motion and hover behaviour a visitor notices, in plain words.

## Business details
Name, address, phone, email, opening hours, social links, and which of them are placeholders.

## Judgement calls
Design decisions that look like mistakes but are deliberate, and why.

## Open items
What is unfinished, placeholder or waiting on the client.

## Revision
Date of this handoff and what changed since the last one.
