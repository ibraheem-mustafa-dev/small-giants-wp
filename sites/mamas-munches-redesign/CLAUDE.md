# Mama's Munches redesign: client design context

The redesign of Mama's Munches (lactation cookies and gifts for breastfeeding mums, Birmingham) from a Claude Design
draft, built fresh on its own test site. It is independent of `sites/mamas-munches/`, which is the sandybrown canary's
folder and its live catalogue; nothing here changes the canary. Business and brand facts (products, pack prices,
audience, story, trust signals) are in `sites/mamas-munches/CLAUDE.md`. Framework rules live in the root `CLAUDE.md`.

## The draft (the reference)

The draft is this folder: one `.dc.html` file per surface, rendered by `support.js` (it stamps `data-dc-tpl` on every
element and sets `window.__dcAnnotatedTemplate`), with the basket shared across pages through `store.js`. Pages link to
each other by file name, so one locally served folder gives every surface its own URL:

```bash
node scripts/computed-route/fill.mjs --serve sites/mamas-munches-redesign --draft-index Home.dc.html
```

Fill takes `--draft-dir sites/mamas-munches-redesign --draft-index Home.dc.html --allow-external` (the draft's
`support.js` loads React and Babel from unpkg.com), and a surface's page is `<served url>/<Page>.dc.html`; the
skeleton writer reads `build/surfaces.json`'s `draftUrl` and the walker reads `SGS_DRAFT_URL`, both the served page.

**Surfaces** (the list in `Wireframes.dc.html`): Home (`Home.dc.html`, the entry), Shop, Product, Gifts, Basket,
Checkout, Confirmation, Contact and Help (`<Name>.dc.html`); the header and footer (`SiteHeader.dc.html`,
`SiteFooter.dc.html`, imported by every page); the nav drawer and the basket drawer (opened states of the header).
`ProductCard.dc.html` is a part the Shop and Gifts pages import.

**Not surfaces, never measured:** `Wireframes.dc.html` (grey wireframes with the designer's block guesses),
`Homepage Directions.dc.html` and `Home-Gift`, `Home-Night`, `Home-Table` (alternative home directions), and
`Mamas Draft Standalone.html` (a single-file bundle of the Basket page only; the folder is the reference).

Every surface page was checked on 2026-10-10 at 375, 768 and 1440: each renders with `__dcAnnotatedTemplate` and its
stamps (Home 514 at 1440).

**`Theme Mapping.md`** is the designer's guess at an SGS block per section plus the new features it needs. Use it as a
cross-check for the skeleton writer, not as truth: it picks core blocks (`core/heading`, `core/breadcrumbs`, which the
framework replaces through `blocks.replaces`), a third-party Instagram plugin, and an `option-picker` where
`sgs/choice-flow` exists. Its token table predates measurement. `github.md` is the design tool's sync note.

## Media

`assets/` holds the eight images the draft renders (logos and product photos, tracked so the draft renders from a
fresh clone). `media/brand/` and `media/photography/` hold the brand logos and real product photography;
`uploads/` holds the designer's source files.

## Theme snapshot

`theme-snapshot.json` is generated by the Spec 33 extractor from the draft, never hand-edited:

```bash
python plugins/sgs-blocks/scripts/theme-extractor/extract.py --client mamas-munches-redesign --draft sites/mamas-munches-redesign/Home.dc.html
```

It writes `theme-snapshot.generated.json`; the measured file is renamed to `theme-snapshot.json`. Measured: text
`#3a2a22`, surface `#fbf3dc`, Young Serif (display), Karla (body) and Caveat (handwritten accents). The extractor took
the dark pink `#a8404f` as primary and left the accent at the framework fallback `#F59E0B`; the draft's logo pink is
`#EE8088` and its logo yellow `#F9CF6E`.
