# Mama's Munches: Phase 0 difference sweep, 2026-11-03

The whole site, compared with the draft at 375, 768 and 1440 px:
- at rest, on hover and with the interactive parts opened;
- measured on the local mirror local-mamas, which matches mamas-test.

Differences are grouped by **cause**, so each cause is fixed once everywhere. The full per-element tables (about 200 rows: measured draft vs live, stored setting, severity) are in the three reviewer files beside this one in `2026-11-03-phase0/`. Bean approves this list once; Round 4 onward applies it one surface at a time.

How it was made:
- Full-page captures with `scripts/computed-route/tools/vision-capture.mjs`.
- Three design-reviewer passes, measured with Playwright on both sides.
- Stored block trees exported from the mirror with `scripts/local-wp/export-block-tree.php`, then scanned for each cause.
- Three reviewer claims re-checked by hand: the string padding, the shop grid tilt and the fixture products.
- The parity walker (`scripts/parity/draft-live-walk.mjs`) needs about 30 minutes per surface. It runs as each round's before/after check rather than gating this list.

Already signed off and excluded: header, footer, and the divergences in `../divergences.json`.
