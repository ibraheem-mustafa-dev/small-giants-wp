## NEW causes (with every element hit on these surfaces)

1. **NEW:padding-string-dropped.** A container padding stored as the plain string object `{"desktop":"40px","tablet":"32px","mobile":"20px"}` (not per-side) emits no CSS: computed padding is 0 and the theme's inline global padding applies instead. Hits: help-82, help-83, help-105, help-106, help-117 (so H13, H14, H15, H17) and contact-20 (C12). Detector: padding/margin values whose keys are devices with string values (5 in tree 152, 1 in 148, none in 157 or 180).
2. **NEW:global-padding.** A container with maxWidth and no padding gets `has-global-padding` + `sgs-container--section-pad` (40px inline) so its content is 80px narrower than the draft. Hits: help-7 (FAQ list 820 vs 900), help-118 (Privacy/Terms), contact-5 (cards and form columns 1160 vs 1240), contact-22 and contact-25 (width only).
3. **NEW:hero-no-vertical-padding.** sgs/hero has no padding or content-width stored. Hits: help-1 (hero 181 vs 368 tall at 1440), contact-1 (hero 269 vs 367, content full-bleed from x10).
4. **NEW:hero-split-mobile-order.** Split hero puts the media first and full-width on phones, flush right on tablet/desktop. Hits: contact-1 / its image.
5. **NEW:label-rest-rotate.** sgs/label with sgsMotion restRotate -9 (and hover rotate -3, translateY -11.98). Hits: help-12, 19, 25, 31, 37, 43, 49, 55, 61, 67, 73, 79 (the FAQ category labels overlap the question text).
6. **NEW:label-default-tracking-and-no-fill.** Chips built from sgs/label carry default letter-spacing and no background. Hits: help-110, 111, 112, 113.
7. **NEW:round-badge-not-square.** A circular badge made from a text/button block has a width but no height, border or fill. Hits: help-14, 21, 27, 33, 39, 45, 51, 57, 63, 69, 75, 81 (FAQ toggles) and help-129 (Message arrow).
8. **NEW:inherited-mobile-font-size.** sgs/text with no fontSize takes the theme's 14px at phone width, draft is 16px. Hits: help-15, 86, 90, 96, 101, 114, 116 (375 only; 768 line-height 23.9 vs 25.6).
9. **NEW:text-maxwidth-centres.** sgs/text maxWidth 700 centres itself with auto margins, indenting the answer 78px. Hits: help-15.
10. **NEW:heading-level.** sgs/heading renders h2 where the draft has an h1 (no h1 on either page), and an extra h2 where the draft uses a span. Hits: help-3, contact-3 (h1 missing), help-127 (stray h2).
11. **NEW:heading-default-tracking.** Heading default letter-spacing -0.015em vs draft normal. Hits: help-85, help-108, help-127, form-send-1.
12. **NEW:search-field.** Standalone sgs/form-field-text has no styling or leading-icon slot. Hits: help-5 and help-4.
13. **NEW:icon-badge-fill-dropped.** sgs/icon backgroundColour slug "whatsapp" unresolved and backgroundColourGradient not emitted, so white glyphs sit on cream. Hits: contact-8, contact-12 (contact-16 renders).
14. **NEW:rest-tilt.** Draft cards sit at rest rotation, live motion defines hover only. Hits: contact-7 (-1deg), contact-11 (+1deg), contact-15 (-0.6deg).
15. **NEW:tiles-styling-and-default / NEW:form-label-typography / NEW:form-field-height.** form-field-tiles and form field labels/heights carry the plugin defaults. Hits: form-send-3, form-send-5..8 labels and inputs.
16. **NEW:drawer-panel-size.** nav-drawer has no panelSize, drawerPadding or scrim set, so it is a full-screen dialog with 43px gutters. Hits: drawer-menu-0, 1, 4, 17..23.
17. **NEW:drawer-double-close.** The dialog's built-in close plus the tree's own x button. Hits: drawer-menu-3 and the built-in button.
18. **NEW:media-needs-fixed-height.** sgs/media without height/aspect/object-fit renders at natural ratio, stretching grid cards. Hits: drawer-menu-7, drawer-menu-12.
