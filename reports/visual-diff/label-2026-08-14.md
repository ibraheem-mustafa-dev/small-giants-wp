## What this report verifies

`edit.js` gained `className="sgs-nested-tools-panel"` on the ToolsPanel inside the
"Typography" PanelBody; `editor.css` gained one rule visually hiding
`.sgs-nested-tools-panel .components-tools-panel-header > h2`. Neither file is a
frontend surface (confirmed by `check-editor-canvas-css.py label`), so this report
verifies the EDITOR CANVAS, not frontend first paint.

## Live measurement

Inserted `sgs/label` on a throwaway page (2430, force-deleted after use), opened the
block editor, selected the block, expanded the "Typography" panel and read the real
computed styles of the inner ToolsPanel's own header:

- `hasClass` (outer panel carries `.sgs-nested-tools-panel`): **true**
- `<h2>Typography</h2>` still present (accessible name intact): text confirmed
- `h2` computed style: `position: absolute`, `width: 0.994318px`,
  `clip: rect(0px, 0px, 0px, 0px)` — genuinely invisible, not `display:none` (so it
  stays in the accessibility tree for screen readers)
- "..." reset-all menu (`aria-label="Typography options"`): still rendered at full
  size (`width: 23.9915px`), fully clickable

Screenshot confirms one clean "Typography" title in the panel list, directly above
the "..." menu and "Font size" control, with no duplicate title text visible.

## Anti-vacuity

The panel was collapsed by default (`initialOpen={false}`, unchanged by this fix)
and was explicitly expanded before measurement — a collapsed panel with unrendered
children would have scored a false PASS on an unmeasured `<h2>`.
