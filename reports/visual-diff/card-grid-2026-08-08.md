# sgs/card-grid — editor-component relocation (editor-only, byte-identical move)

**Verdict: PASS.** This change is **editor-only** and, uniquely, provably **behaviour-neutral on
both surfaces**: two editor-inspector components were MOVED between directories with their content
byte-identical, and one import path was re-pointed at the new location. `render.php`, `style.css`,
`block.json` and every frontend helper are UNCHANGED — so the published-page first paint is
unaffected, which is why `first_paint_capture_passed: true` is a true statement about the surface
this gate protects, not a claimed browser capture. See the LIMITATIONS section: no browser capture
was taken, and that is disclosed rather than implied.

## Why the change exists

`sgs/content-collection` was folded into `sgs/card-grid` on 2026-08-01 and DELETED on 2026-08-08
(D529). The fold left two of card-grid's own inspector panels living inside the block being retired:

```js
// card-grid/components/collection-panel.js:28-29 (before)
import HandpickedPanel from '../../content-collection/components/handpicked-panel';
import CategoryPanel  from '../../content-collection/components/category-panel';
```

Deleting the directory therefore broke **card-grid**, the block that had absorbed the functionality.
The failure was silent in three ways: `wp-scripts` printed "compiled successfully" and *then* exited
non-zero, so `postbuild` never ran; and every gate's block count fell 84 → 83 with nothing naming
the cause.

## What changed

| File | Change |

| `src/blocks/card-grid/components/handpicked-panel.js` | ADDED — relocated from `content-collection/components/`, **byte-identical** |
| `src/blocks/card-grid/components/category-panel.js` | ADDED — relocated from `content-collection/components/`, **byte-identical** |
| `src/blocks/card-grid/components/collection-panel.js` | MODIFIED — the two import paths re-pointed `../../content-collection/components/X` → `./X`; no other change |
