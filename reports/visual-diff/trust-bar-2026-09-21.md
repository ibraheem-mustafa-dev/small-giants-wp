## Follow-up: the marquee with no breakpoint now starts (deploy of this change, same probe page 46, real browser)

Cause (proven, pre-existing, identical with the old `view.js`): with autoScroll on and no breakpoint the track was a shrinkable flex item, so it was never wider than the
bar and the overflow check saw nothing to scroll. Fix: the same non-shrinking single-row rules the breakpoint mode uses are now emitted for every width, and `view.js`
marks the row before measuring.
