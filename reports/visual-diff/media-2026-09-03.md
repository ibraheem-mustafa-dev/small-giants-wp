## What changed

`captionColour` gained a gradient sibling and a gradient-capable paint path, following the
CURRENT `sgs/counter` `labelColour`/`labelColourGradient` pattern (commit `305f9170c`).
`sgs/media` is heavily atomised — its shared media atoms live in `src/components/media/**` —
but `caption` is NOT one of the shared atoms; the caption element and its `captionColour`
attribute are declared and rendered entirely inside `src/blocks/media/` (block.json's
`caption` element, `render.php` step 8, `edit.js`'s `SgsColourPanel` row). No file outside
`src/blocks/media/` was touched.

| File | Change |
|---|---|
| `block.json` | new `captionColourGradient` string attr; the existing `caption` element (which previously had NO `attrMap` at all) gains `"css:color": "captionColour"` (documenting the pre-existing flat path) + `"css:background-image": "captionColourGradient"` |
