## What changed

Added a per-item `decorative` field (boolean, default `false`) to the typed `items[]`
repeater's item schema — this block's card image has no scalar per-block attribute, only
a per-card `media` field, so the decorative flag follows it into the repeater (matching
`sgs/brand-strip`/`sgs/gallery`/`sgs/trust-bar`'s identical shape, all fixed the same
session). `edit.js`'s `ItemEditor` gets a `ToggleControl` next to the `MediaPicker`;
`render.php` blanks that card's alt and adds `aria-hidden="true"` to the
`.sgs-card-grid__image-wrap` wrapper (not the shared `sgs_render_media()` helper itself,
which has no `aria-hidden` hook and is used by many other blocks). The block's
WooCommerce-bound modes (`source: 'wc-product'`/`'cpt-collection'`) render via
`ServerSideRender` from a live product/CPT query and never touch the manual `items` array —
the toggle is correctly reachable only for manually-authored cards.
