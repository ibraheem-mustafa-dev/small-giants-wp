## ⛔ Correction to the earlier report

The previous version of this file said info-box *"has NO typography emitter (`grep -c
"text-align" render.php` = 0)"* and that its typography controls were non-functional.
**That was wrong.** The grep was the wrong instrument: this block emits typography through a
wholesale passthrough —

```php
$base_style_engine_args['typography'] = $style_typography_args;   // :271
wp_style_engine_get_styles( $base_style_engine_args, array( 'selector' => $root_sel ) );
```

— which never contains the literal string `text-align`, so a grep for it returns 0 on a file
that was already emitting typography correctly, to the correct selector.

**The real gap was one property, not all of them.** `block.json` declares seven typography
supports; six ride the passthrough. `textAlign` alone cannot: it is not a style-engine key, so
`wp_style_engine_get_styles()` silently ignores it — the same reason `sgs/notice-banner` and
`sgs/cta-section` each emit it by hand.

An initial implementation replaced the passthrough with a hand-enumerated list of six
properties. That was reverted: it covered today's supports exactly, but any support added later
would silently stop emitting, and it contradicted this block's own documented
"wholesale-passthrough pattern" (`render.php:22`). The passthrough is restored and only the
text-align emit added.

## Why the root selector

The block renders its heading and description as InnerBlocks children, so typography is carried
by plain CSS inheritance — what core does (`core/group`, `core/cover`, `core/columns` all declare
typography supports with no child selector). A DECLARATION beats an INHERITED value regardless of
specificity, so an unset child inherits the container value and any child that sets its own wins.

⚠ Known limit, same as cta-section: `font-size` will not reach a heading child, because
theme.json `styles.elements.h2` declares one and a declaration beats inheritance. Correct
behaviour, not worked around.

## Risk

No markup change. New output is a single `text-align` declaration in the block's existing scoped
`<style>`, emitted only when an operator sets an alignment. An unset block renders byte-identical.
