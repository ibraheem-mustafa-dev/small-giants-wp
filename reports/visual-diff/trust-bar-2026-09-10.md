## What changed

Added an editor-facing border control for the icon-circle badge
(`.sgs-trust-bar__circle`). The border was previously hardcoded as a single
unconditional CSS fallback in `style.css` (`border: var(--sgs-trust-badge-circle-border,
1px solid rgba(0, 0, 0, 0.08))`) with no attribute ever writing
`--sgs-trust-badge-circle-border` — an operator (or the cloning pipeline, matching the
Mama's Munches draft which has no badge border) had no way to turn it off.

New attributes `iconCircleBorderWidth` (4-side box object, `box_family`),
`iconCircleBorderStyle`, `iconCircleBorderColour` — box-object contract (Spec 32 §6.1),
mirroring `sgs/hero`'s `splitMediaBorderWidth` family shape. `style.css`'s single
`border` shorthand split into three independently-overridable declarations
(`border-width`/`border-style`/`border-color`), each keeping its own framework-default
fallback so an unmodified instance is unaffected. Wired via the existing
`SgsBorderControl` component in the icon-circle "Appearance" panel, plus an
editor-canvas mirror (`boxShorthand()` on the block wrapper's inline custom
properties) so `check-editor-render-parity.js` CHECK A stays green.

## Why intent capture, not before/after

This is a new, previously-unreachable capability (there was no control to move — the
custom property it now drives was never set by anything). "Before" is not a rendered
state to diff against; the real question is whether the default is unchanged and the
override genuinely works. Both are asserted below and measured live.

## Assertions

1. An unmodified trust-bar instance (attribute unset) renders the exact same border as
   before this change: `1px solid rgba(0, 0, 0, 0.08)`.
2. Setting `iconCircleBorderWidth` to `{top:'0px',right:'0px',bottom:'0px',left:'0px'}`
   removes the border entirely (computed `border-width: 0px`).
3. No inline `style="..."` attribute is emitted on the rendered element (Spec 32
   FR-32-4/FR-32-1) — the override rides a scoped custom-property VALUE only.

## Risk

to the identical computed value for any instance that never sets the new attributes
(proven above). New CSS custom properties only appear when an operator opens the new
"Icon circle border width" / "Icon circle border colour" control.
