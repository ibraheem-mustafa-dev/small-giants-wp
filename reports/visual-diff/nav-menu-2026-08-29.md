## What changed

`block.json` only. Two things, both classification/serialisation, no markup and no CSS:

1. `supports.color` added as `{background:false, text:false, gradients:false,
   __experimentalSkipSerialization:true}` — declares the capability to WP while telling core
   NOT to inline it, so the block keeps emitting its own scoped CSS (Spec 32).
2. `navBg` / `navColour` / `navBgHover` consolidated into the wrapper element's `attrMap`,
   which is what let the derived layer resolve `navColour`/`navBgHover` (previously NULL).

## Why intent-capture, not before/after

A `__experimentalSkipSerialization` declaration is a NEGATIVE assertion: the correct outcome is
that nothing changes visually and no inline style appears. A pixel diff of "before" against an
identical "after" is a null image by construction. The assertion is therefore stated and
measured against the live DOM.
