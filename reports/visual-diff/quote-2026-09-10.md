## What changed

`italic` to `normal` — Bean-directed design decision (root-caused earlier this session,
approved directly, not re-litigated here). Italic is now opt-in per instance
(`attributionFontStyle` on `sgs/quote`, `fontStyle` on `sgs/text`), not the block's resting
state. No converter/render.php code changed — the typography-population path for both

`attributionFontStyle`, `resolvers/typography.py`'s pre-layer dispatch for `sgs/text`'s
`fontStyle`), so a draft with an explicit `font-style` declaration already gets it written;
only the CSS fallback for drafts with none needed flipping.
