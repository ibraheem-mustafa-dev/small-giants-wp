# sgs/post-grid — card custom-property VALUES moved from per-card inline to one scoped descendant rule

**Verdict: PASS.** Live capture confirms every rendered `.sgs-post-grid__card` carries NO
`style` attribute, and the per-instance colour custom property resolves correctly via a
single scoped descendant rule on the block root.

## What changed
`plugins/sgs-blocks/src/blocks/post-grid/render.php` line 458:
```php
$responsive_css .= $root_sel . ' .sgs-post-grid__card{' . Post_Grid_REST::card_vars_decls( $card_params ) . '}';
```
The card custom-property VALUES (e.g. `--sgs-pg-title-colour`) used to ride inline on EVERY
card root, written by `plugins/sgs-blocks/includes/class-post-grid-rest.php` (also changed
this wave — the card renderer used by both the initial server render and the AJAX
pagination `view.js` path). They are per-BLOCK-INSTANCE, not per-card, so a single scoped
descendant rule on `.sgs-post-grid__card` covers every card — including cards injected later
by AJAX pagination, since CSS rules apply to matching DOM regardless of when that DOM is
added, and the new cards land inside `.sgs-post-grid__inner`, still within the scoped root.

## Live evidence
- **URL:** `https://sandybrown-nightingale-600381.hostingersite.com/f3-oracle-sgs-post-grid/`
- **Method:** Playwright, `getAttribute('style')` + `getComputedStyle(el).getPropertyValue('--sgs-pg-title-colour')`
  on `.sgs-post-grid__card`, at 1440px and 375px viewports.
- **Result (both viewports, identical):** card element
  `class="sgs-post-grid__card sgs-post-grid__card--card"`, `styleAttr: null`. Computed
  `--sgs-pg-title-colour: #e68a95` — a non-default value, confirming the scoped rule (not a
  CSS fallback) is supplying it.
- This is consistent with, and reproduces independently of, the value already recorded as
  live-verified in this wave's deploy note (`#aa0000` on a different canary instance) — same
  mechanism, different configured colour, both non-default and both style-attribute-free.

## Limitation
Only one card matched the selector on the sampled page's initial viewport (the grid may
paginate more cards via AJAX; those were not exercised in this pass). The mechanism (a
descendant selector on the block root) makes AJAX-injected cards structurally covered by the
same rule, but that specific runtime behaviour (pagination click → new card → still no
inline style) was not separately captured this session.
