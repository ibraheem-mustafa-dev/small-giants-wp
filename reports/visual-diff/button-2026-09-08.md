## What changed

The base `.sgs-button` rule read `border-radius: var(--sgs-mb-btn-radius-default, 10px)`. The
`10px` FALLBACK was a hardcoded default that painted rounded corners onto every preset-less
button whose source draft declares no radius at all — the "faithful absence" failure this
project's own rule names ("hardcoded wrapper defaults are CHEATS to remove").

It is now `var(--sgs-mb-btn-radius-default, 0)`, and the framework's designed rounded look moved
onto the three preset classes (`--primary` / `--secondary` / `--outline`) as `border-radius: 10px`.

This is the same fix, on the same element, that was applied to `border-width`/`border-style` one
line above on 2026-08-27 — for the same button on the same page. `border-radius` was missed then;
this closes it. The group-default custom-property tier is untouched (it is a real operator
mechanism, D638 §4); only the literal is gone.
