## What changed

`sgs/card-grid` declared WordPress's native `__experimentalBorder` support (radius, width,
colour, style). `migrate-border-shape-b.js --survey` had refused to migrate it because
`render.php` accumulates CSS into three separately-named `*_css` variables
(`card_grid_native_css`, `sgs_grid_typo_css`, `card_grid_stagger_css`) and the script's
name-based disambiguation couldn't tell which one was the border sink. The script was widened
to trace which accumulator structurally receives the output of the border-specific
`wp_style_engine_get_styles()` call — `$card_grid_native_css`, confirmed by reading the file
directly before touching anything. Border width/style/colour/radius are now block-private
attributes (`borderWidth`, `borderStyle`, `borderColour`, `borderColourGradient`,
`borderRadius`/`Tablet`/`Mobile`) with their own `render.php` emission (Shape B), matching
`sgs/accordion`'s proven pattern.

## Assertions — stated before measuring

1. A palette-token border colour paints the resolved token colour on the block, not
   `transparent` and not the raw slug.
2. Border width and style paint from the block-private attributes.
3. **Negative control:** `borderStyle: "none"` paints no border at all — no width, no style.

## Why before/after doesn't apply

Unlike `sgs/accordion` (whose native border path was structurally dead code), `card-grid`'s
native border support DID render before this migration — this is a genuine behaviour-preserving
storage move, not a dead-code removal. A live before/after diff on the canary itself was not
practical within this session (the migration and its capture both landed in the same pass,
and the canary is pre-production with no client content to protect — CLAUDE.md: "the framework
is PRE-PRODUCTION — a default changing costs nothing, and there is no content to protect").
The positive+negative live pair above is the load-bearing evidence instead: it proves the NEW
mechanism paints correctly and the negative control stays clean, which is the property that
matters for any future instance of this block, migrated or freshly authored.
