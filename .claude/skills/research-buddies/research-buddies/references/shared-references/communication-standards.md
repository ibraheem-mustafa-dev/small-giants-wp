# Communication Standards

How to write for Bean (plain English, self-contained decisions, Problem → Effect → Solution, UK English) is set once, in the Communication section of `~/.claude/CLAUDE.md`, which every session loads. This file adds only what applies to quality reports.

## Gap registers (gap-analysis, skill-optimiser, qc)

- Grades measure opportunity value (how much filling the gap is worth), not severity.
- List every gap, not a top 3.
- B and C grade gaps go into the target's plan, spec or `references/backlog.md`; they never disappear.
- List only gaps in the target itself; tooling, system and other-skill issues go in a separate "excluded" table.
- Every section of the report template is filled; write "None found" rather than skipping one.
