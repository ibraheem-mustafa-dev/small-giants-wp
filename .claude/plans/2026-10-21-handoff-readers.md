### The readers and the shared fact record (the design)

Each reader takes one handoff family and writes its part of the fact record; the census and the construct readers stay the sources they already are, and nothing below reads a draft by regex or runs draft logic in Node (FR-48-24).
- `lib/read-template.mjs`: per draft, the element records of the runtime's annotated template, read in the sandboxed page through `__dcAnnotatedTemplate` as the census does (`lib/intake-census-template.mjs::draftSources`, `::readStamped`): tag and real tag, every attribute, the static declarations and `style-*` rules, each hole with its logic path, the template parent chain, `sc-if`, `sc-for` (list and item names) and `dc-import` membership, ref, hooks and events.
- `lib/read-logic.mjs`: in the sandboxed page, for each read width set by the viewport (so a draft that measures its own container, Eye Care, sets its own tier), the value each hole resolves to through the live logic instance's `renderVals()` (READING-DC-FILES §1), for every element, including those the width does not render; the width condition of every `sc-if` from the syntax tree (`lib/intake-ast-eval.mjs::evalDeep`, `::staticTruth`).
- `lib/read-surfaces.mjs`: each element's surfaces (`surfaces.json` id, kind, parent, the states whose `sc_if_tpl_ids` contain it or an ancestor, part roots).
- `lib/read-animations.mjs`: the effects that target the element or a descendant (`animations.json` ids, by containment), with their triggers, breakpoints and routes.
- `lib/tokens.mjs` (built): the token each literal equals by value.
- `lib/read-assets.mjs`: each asset's intrinsic ratio (SVG viewBox, raster size) and the element that uses it.
- `lib/read-readme.mjs`: the README's sections split by `README.template.md`'s headings, its judgement calls, open items and platform intent kept as evidence (FR-48A-8, FR-48A-10).
- `lib/fact-record.mjs`: joins them into `sites/<client>/build/intake/facts.json`, one entry per template key with its instance keys per state, its fingerprint, and a `sources` header (`assertCurrent` refuses a stale record), written by intake only and re-aligned to a new export by fingerprint. Every stage reads its facts through this loader; each wave names the old read it retires.
