## Deferred design

**Next loop, first fix: the default residue pass (Bean, 2026-10-31: clone now, build after).** Spec 48 R-47-4 and R-47-5 intend a block default the draft never states to be reset where the draft's rendered value differs, but Fill reads only the longhands the draft's code declares (FR-48-8), so an SGS default the draft lacks (the built-in hover transitions: census 2026-10-28, 1,331 rows; likely part of the margin, line-height and colour rows) is never compared and stays live. The pass compares, on draft-paired elements only, each block's calibrated default paint with the draft's rendered value for visual properties only (transitions, colours, backgrounds, borders, shadows, margins and padding, text spacing), at rest plus the states the draft draws, against the parent's live value for inherited properties, and resets the difference through a setting, else the Custom CSS writer. It never touches functional mechanics (`display`, `position`, `overflow`, `z-index`, `visibility`, `pointer-events`, `transform` and `opacity` start states), focus and focus-visible styles, screen-reader text, block-only parts (slider arrows, pause buttons) or layout-dependent sizes (height, offsets). MUST FAIL: a block-default transition the draft lacks is reset; negative controls for each guard (a drawer's `display:none`, a focus ring, a slider arrow, an inherited colour). Line heights (Bean, 2026-10-31: make them controllable): 49 block stylesheets hard-code 122 literal line heights and only 2 rules read a token, so the theme's typography defaults never reach those parts; 53 blocks already carry 164 line-height settings, and of the 49 hard-coding blocks 37 have one and 12 have none (DB `block_attributes.css_property = 'line-height'`, 2026-10-31). So the pass writes the block's own line-height setting wherever one exists, and the 12 blocks without one gain the control (every customisable property has an inspector control; a migration under the migration-method skill, detector first), so the reset is native, never Custom CSS.
