# Handoff data register (2026-10-21)

Every kind of data a Claude Design handoff folder holds (Spec 48A), measured on the three current exports (`sites/indus-foods/handoff/`, `sites/mamas-munches-redesign/handoff/`, `sites/eye-care-ward-end/handoff/`), with every stage of the computed route (Spec 48) that could use it, its use by AI agents, what the specs say, what is built and the gap. Built by read-only analysis agents, one per file family; each report's load-bearing claims were re-checked by the main session (the "Checked" lines).

Stages: (1) handoff check, (2) intake, (3) skeleton, (4) Fill (values, states, motion, media, content), (5) calibration, (6) site build and theme snapshot, (7) build into posts, (8) Solve and live checks, (9) review and divergence ledger. AI-agent use: (a) evidence that clears an ambiguity in the primary sources for an agent or the skeleton finaliser; (b) patterns to analyse into rules, so agents decide less.

## Joins and coverage

- Every `template_tpl_id` and `sc_if_tpl_ids` in Indus `surfaces.json` (323) and every element id in `animations.json` (304) resolves in the stamped template tree; the files join to template elements exactly. Checked: Indus S-04 "About mega menu" is kind `menu`, root `[63, 66]`, parent `S-03`, open state `{active:1}` flips `sc-if` 63, 66 and 75.
