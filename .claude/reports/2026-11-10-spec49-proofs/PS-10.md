# PS-10: Pinned background on the real element (2026-11-10)

**Verdict: PASS.** Static pages in Chrome and desktop Playwright WebKit, at 1440 and 375, on a 3000px page with an 800px section. Painted frames: Chrome screencast with `Input.synthesizeScrollGesture`; WebKit wheel steps with a screenshot after each. The main thread checked `run3.log`: band range 0, gap frames 0 and magenta frames 0 in every run.

| Test | Result |
|---|---|
| Photo still, no gap at any edge | Pass. Band range 0px; the deterministic edge check (`edge.mjs`) found at most 1px |
| A background colour on the section | Pass. Magenta 0 frames: the colour paints under the `z-index:0` element, so it no longer hides the photo |
| A 40% overlay and an SVG divider | Pass. The stack is divider, overlay, photo, section; the photo darkened to 0.6, the divider not darkened |
| Reduced motion | Pass. It computes `scroll`, and the photo scrolls with the section |
| `overflow:clip` on the section | No interaction: hidden, clip and the hidden-then-clip pair all pass |
| iOS reset | Cover's rule, copied verbatim from Gutenberg trunk `cover/style.scss` `.has-parallax`. Untested: no iOS device |

## CSS

`.sgs-bg-media`:
- `position:absolute; inset:0; z-index:0`
- the background image, with `background-size:cover`, `background-position` from Focal, `background-repeat:no-repeat` and `background-attachment:fixed`
- `@supports (-webkit-touch-callout: inherit)` and `@media (prefers-reduced-motion: reduce)` both reset it to `scroll`.

The overlay is `z-index:1`, the divider `z-index:2`, and the content `position:relative; z-index:3`. The section is `position:relative; overflow:hidden; overflow:clip`.

## Spec changes

1. **§7.8.** Spacing inside the section is padding. A first child's margin collapses through the section, and an early run lost 100px of photo that way.
2. **§10.3.** Record the proof, and record the iOS reset as Cover's rule, untested on a device.
3. **A known CSS rule, untested here.** `background-attachment:fixed` stops being fixed under any ancestor with `transform`, `filter` or `will-change:transform`. An SGS entrance animation transforms the section it is set on, and a held end state keeps doing so. Pinned and a transform entrance on the same block therefore conflict. AC-20 tests Pinned under a block with an entrance.
