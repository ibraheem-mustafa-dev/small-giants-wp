## New false-positive patterns
1. **Wrong-level pairing**: rows 1 and 3 name a block root but quote a value measured on a descendant (link, inner row). A fix is to compare the same element tier and reject a pair whose measured element is not the named block's root.
2. **Flex gap on a single child** (row 6): any gap/column-gap where the container has fewer than 2 rendered children paints nothing; filter it out.
3. **Hidden-element measure** (row 4): the closed mega-panel button is 0x0 (visibility hidden); the 54x31 style numbers come from different open states or a label span. Measure only when the panel is open on both sides.
4. **Repeated wrapper padding** (rows 2 and 5): live has an extra padded wrapper that the draft lacks. The child width drop is a symptom; the cause is padding at two nested levels, so one finding should cover the card and its descendants (not one per item).
5. Mild: draft elements have inline `style` plus no class names, so the walker has no semantic anchor to the draft side; pairing relies on position and is where the mismatches in 3 and 4 appear.
