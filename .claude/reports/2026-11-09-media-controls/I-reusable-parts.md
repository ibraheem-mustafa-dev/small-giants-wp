# I. Reusable parts for the media system (mechanical enumeration, worktree E:/sgs-tmp/wt-indus)

Method: grepped plugins/sgs-blocks/src, includes and theme/sgs-theme for mask, mask-image, clip-path, shape, blob, svgMask, sgs_shape, sgs_mask and the rest of the list, then queried sgs-framework.db block_attributes for css_property in (clip-path, mask-image, aspect-ratio, object-fit, filter, mix-blend-mode) and attr names like %hape%. Every item below was opened and read, not inferred from names. Paths are relative to plugins/sgs-blocks unless stated.

## 1. Mask and shape capabilities (the census missed most of these)

### 1.1 box-shape atom, named shape (the only shape vocabulary shared across blocks)
Files: src/components/media/atoms/box-shape.js (657 lines, pure logic), box-shape.control.js, src/components/media/controls/MediaBoxShapeControls.js (the JSX rows), includes/media/atoms/box-shape.php (481 lines, byte-parity PHP twin, `sgs_media_atom_box_shape_clip_paths()`, `_validate_shape()`, `_css()`). Attribute: `{prefix}Shape` enum none | rounded | circle | square (per-surface prefix, e.g. `splitMediaShape` on hero). Render: `clip-path` only (square inset(0), rounded inset(0 round 12px) with a fixed 12px constant, circle circle(50%)). Control: a ToggleGroupControl labelled "Shape" in the Box shape rows. Not per-device (Shape is not in MEDIA_TIERED_BASES). Quality: solid and gated (JS/PHP parity test), but the vocabulary is only four shapes, rounded radius is hard-coded, and it is clip-only (no mask-image, so no blob, arch, organic or custom SVG). Adopters of the atom: sgs/media and sgs/hero (splitMedia). Reuse: use as is for the four basics, extend the enum and the CLIP_PATHS map (one map in JS, one in PHP) for more shapes.

### 1.2 decorative-image layer shape (re-uses 1.1 vocabulary on a different block)
src/blocks/decorative-image/block.json attribute `shape` (enum none, rounded, circle, square, default none, attrMap `css:clip-path`), render.php calls `sgs_media_atom_box_shape_validate_shape()` and `sgs_media_atom_box_shape_clip_paths()` and prints `clip-path` on the layer root so fill, border, shadow, image and content clip together. A shape alone paints nothing (needs border, fill or shadow, else the layer does not render). Plus per-device `borderRadius`, `boxShadow`, `height`, `rotation` on the same layer. Reuse: this is the proof that the clip map can be consumed by a block that does not adopt the whole atom. Layer controls: src/blocks/decorative-image/layer-preview.js.

### 1.3 hero split media shape
src/blocks/hero/render.php (`$image_shape` from `splitMediaShape`, emits `.uid .sgs-hero__split-media{clip-path:...}`), via box-shape atom, declared in hero block.json supports.sgs.mediaElements prefix `splitMedia` with atoms source, object-fit, focal-point, box-shape, media-padding, overlay, shadow (prefix `split` has media-type). This is the fullest atom stack on a block other than sgs/media.

### 1.4 end-shape (true mask-image on a box end; the most advanced mask code in the repo)
includes/helpers-end-shape.php (273 lines) and editor twin src/utils/end-shape.js (244 lines, returns identical strings). Cuts a left or right end of a box into a shape from the shape-divider library using a data-URI SVG tile as `mask-image` with `mask-size:auto 100%` and `mask-composite:subtract` so the box fill and its real CSS border are cut together. Used by sgs/label only (attrs `endShapeLeft`, `endShapeRight` enum '' | arrow | triangle | slant | curve | wave-smooth | zigzag, plus `endDepth` 10 to 150 percent). Render in src/blocks/label/render.php. Quality: high, but it is an END cut on a text pill, not an image mask. Reuse: the data-URI SVG tile plus mask-composite technique and the allowed-shape list are the best starting point for an SVG-path mask on images; adapt, do not use as is.

### 1.5 shape dividers (SVG paths, not masks)
includes/shape-dividers.php (625 lines, `sgs_get_shape_dividers()`, `sgs_render_shape_divider()`, `sgs_shape_divider_axis()`, `sgs_shape_divider_decls()`, gradient defs) and src/utils/shape-dividers.js (SHAPE_DIVIDER_PATHS, 15 paths: wave, wave-smooth, triangle, triangle-asymmetric, curve, curve-asymmetric, zigzag, cloud, slant, slant-gentle, mountains, drops, tilt, arrow, split; viewBox 1200x120). Block attrs `shapeDivider{Top|Bottom}` plus Colour, ColourGradient, Flip, Invert, Scale on sgs/container, sgs/hero, sgs/site-footer, sgs/trust-bar via SGS_Container_Wrapper. Editor: src/components/ShapeDividerPreview.js. Section-edge decoration, not an image frame. The path library is reusable as source geometry for masks.

### 1.6 icon shapes (box shapes plus custom outline paths)
includes/data/icon-shapes.json (custom outlines, each one SVG path in a 0 0 100 100 viewBox, e.g. star), includes/helpers-icon.php (`sgs_icon_outline_shapes()`, `sgs_icon_outline_svg()` which uses an SVG clipPath), src/utils/icon-shapes.js (BOX_SHAPES square, circle, pill; OUTLINE_SHAPES), src/blocks/icon/shape-options.js (`shapeOptions()`, ShapeToggle, CanvasOutline). Attrs: `shape` on sgs/icon; `childIconShape`, `childIconShapeSize` on sgs/social-icons; `iconShapeSize` on sgs/button. This is the only data-driven shape registry (JSON, PHP and JS read the same file). Quality: good pattern. Reuse: the JSON-registry pattern (slug, label, path in a 0 0 100 100 box) is the right model for a media shape library, and the paths themselves can feed a mask.

### 1.7 team-member photoShape
src/blocks/team-member/block.json `photoShape` (string, default circle); render.php emits class `photo--circle|square|rounded` (the DB lists no css_property, so it is class-driven styling in style.css, three values, no enum in block.json). Also `sgsObjectFit`/`sgsObjectPosition`/`sgsColourTreatment` via the atoms. Weak: an unconstrained string and class-based. Not reusable beyond showing the pattern the atom should replace.

### 1.8 buybox gallery sticker shape
src/blocks/buybox/gallery-sticker.php `sgs_buybox_gallery_sticker_css()`: `galleryStickerShape` enum rounded | pill | tag; tag prints `clip-path:polygon(0 0,100% 0,88% 50%,100% 100%,0 100%)`, pill prints `border-radius:999px`. Editor preview: gallery-sticker-preview.js. This is the only polygon clip-path preset. Small, block-private; the polygon is reusable as a preset.

### 1.9 label marker icon mask
src/blocks/label/render.php (~335 to 349) builds a Lucide icon as `mask:url("data:image/svg+xml,...") center/contain no-repeat` on `::before` (DB: label.markerIcon css_property mask-image); preview in label/dot-preview.js. A real mask-image used to recolour an icon with currentColor. Reusable technique for single-colour SVG assets (recolourable stickers), not for photos.

### 1.10 Other clip and mask users (not shape controls)
before-after clip-path comparison split (src/blocks/before-after/render.php, media-render.php); motion clip reveal (includes/motion/class-sgs-motion-clip-edge.php, `--sgs-me-clip-t|r|b|l`, composed to `clip-path:inset()` in assets/css/motion.css); SVG part wipes (src/shared/svg-parts/frames.js CLIPS); morph shape pairs (includes/fx-shape-routes.php, fx-shape-routes.json, `data-sgs-fx-shape`, circle-square style pairs for MorphSVG); ColumnShapePicker.js (column layout diagrams, not media); container border mask via `::before` (includes/class-sgs-container-wrapper.php), accounts/timeline/mega-panel/tabs/cursor-field CSS masks (decorative). gallery/card-grid have none.

### 1.11 What does NOT exist (searched: blob, arch, svgMask, sgs_shape, sgs_mask, mask-image on img, maskImage in attributes)
NOT FOUND: any user-pickable blob, arch, organic or custom-SVG mask on an image or video; any `maskImage`, `blob`, `arch` or `svgMask` attribute on an SGS block (the DB shows `blob` only on core/* blocks as a core media field); any `sgs_shape_*` or `sgs_mask_*` PHP function (the nearest are `sgs_media_atom_box_shape_clip_paths`, `sgs_end_shape_*`, `sgs_get_shape_dividers`, `sgs_icon_outline_shapes`); any per-device shape; any theme-level mask utility (theme/sgs-theme only has mask in focus.css and assets/css utilities, woocommerce and shop-load-more as incidental UI). So the owner's "mask and shape controls in other blocks" are: box-shape (clip-path named shapes, on media, hero, decorative-image), end-shape (mask-image on label), icon-shapes (JSON path registry), shape dividers (container family), sticker tag polygon, team photoShape.

## 2. Media atoms (src/components/media/atoms and includes/media/atoms)

Architecture: registry src/components/media/atoms/registry.js (MEDIA_ATOMS: id, bases, types, scope, attachesTo, requires, reads, disclosure, css) declares data only; each atom has a pure logic module (`<atom>.js`, plain-Node importable, enforced by scripts/check-media-atom-purity.js), a JSX `<atom>.control.js` returning bare rows, and a PHP twin includes/media/atoms/<atom>.php (`sgs_media_atom_<id>_requires()`, `_css()`), byte-parity checked by scripts/tests/test-media-atom-parity.mjs. Naming and injection: src/components/MediaElementControls.js (MEDIA_BASES 59 bases, MEDIA_TIERED_BASES, MEDIA_ATTR_TYPES, STORED_AS, `mediaAttrKeys(prefix)`, `mediaStoredAttrName(slug, prefix, base)`) and src/blocks/extensions/media-elements.js (selective attribute injection from `supports.sgs.mediaElements: [{prefix, context, atoms}]`, never overrides a block's own declaration). Dispatch: src/components/MediaElementPanel.js (mounts atoms' controls in registry order, gated by mediaType and scope, `insertion: 'root'` opens its own InspectorControls panel, `'element'` returns bare rows for the host panel). Server: includes/class-sgs-media-element.php (`Sgs_Media_Element::style()`, `box_classes()`, `requires_box()`, `fills_box()`, `scope_class()`) and includes/helpers-media-element.php (`sgs_media_element_value()` normalises the five stored shapes, `sgs_media_element_style()`, `sgs_media_hover_zoom_clips()`). Disclosure vocabulary is closed: state is shown | disabled | omitted, with hiddenReason text for disabled; video-behaviour returns a per-base map. CSS declarations have no trailing semicolon and emit nothing for an empty attribute set. Per-device: only the bases in MEDIA_TIERED_BASES carry Tablet and Mobile siblings (all source and video behaviour bases, ObjectFit, ObjectPosition, Height, Width, MinHeight, OverlayOpacity, BorderRadius, Padding); a blank tier inherits the tier above.

Atoms (15), with bases, types, disclosure and mounts:
1. source (ImageId, ImageUrl, VideoId, VideoUrl, SvgContent, Thumbnail, ThumbnailId, LottieId; types image, video, svg, lottie; scope both; box). Per-device sources (the per-device image picker). Picker hard-restricted by type. Mounted: sgs/media, hero `splitMedia`. Reads five legacy storage shapes (product-card bare URL, decorative-image decorMedia, before-after before/afterImageId, media legacy thumbnail strings).
2. media-type (MediaType, VideoSource, VideoMimeType; all types; element). Tier enum with '' = inherit. Disclosure always shown. Mounted: sgs/media, hero `split`. sgs/container has no type attribute (type inferred, video silently beats image): a known gap.
3. video-behaviour (VideoAutoplay, Loop, Muted, Controls, PlaysInline, LazyLoad, Captions Id/Url/Label/SrcLang, LottieTrigger, LottieSpeed; video, lottie). Per-device tiered. Disclosure is a MAP: autoplay locks muted and playsinline (disabled with a reason). Mounted: sgs/media only (other video surfaces hardcode these server-side: a gap).
4. meaning (ImageAlt, VideoAlt, ImageDecorative; image). Disclosure: alt disabled when decorative. Mounted: sgs/media, measured-diagram.
5. intrinsic (ImageWidth, ImageHeight; written from the chosen media, not edited; disclosure omitted). Mounted: measured-diagram drawing.
6. svg-presentation (SvgAnimation, SvgAnimationSpeed, SvgOpacity, SvgPosition, SvgMinHeight, SvgTextShadow; svg). Disclosure: speed disabled until an animation is chosen. Mounted: sgs/media.
7. object-fit (ObjectFit, Size; image and video; scope both: object-fit for replaced elements, background-size for painted boxes, one control). Per-device ObjectFit. Always shown. Mounted: the widest of all, 24 surfaces (media, hero, decorative-image, before-after, brand-strip, buybox main and thumb, card-grid, cart, gallery, google-reviews, image-sequence, mega-panel, option-picker swatch, post-grid, product-card main and thumb, product-search, team-member, testimonial avatar and work, trust-bar badgeImage).
8. focal-point (ObjectPosition, Position, Repeat, Attachment; image and video). Per-device ObjectPosition. Disclosure: shown only when the fit crops (cover, contain, scale-down), else disabled with a reason. Mounted: media, hero, decorative-image, before-after (both), product-card main, testimonial work.
9. box-shape (MediaSizing, AspectRatio, Shape, Height, MaxHeight, MaxWidth, MinHeight, Width, BorderRadius per device, BorderWidth, BorderStyle, BorderColour, BorderColourGradient, BorderColourHover, BorderColourHoverGradient). Mode is auto | height | ratio | fill, with height and ratio mutually exclusive (registry `requires`), ratio emitted as spaced "16 / 9" and both forms read. Mounted: sgs/media and hero splitMedia only. Border paint is SgsBorderControl fed the atom's own names; per-device border width is cancelled by Bean (2026-08-29).
10. overlay (OverlayColour, OverlayColourHover, OverlayGradient, OverlayGradientHover, OverlayOpacity per device, OverlayBlendMode). Disclosure: opacity and blend disabled until a colour or gradient is set. Mounted: media, hero splitMedia, decorative-image.
11. opacity (Opacity; image, video, svg). Always shown. Mounted: sgs/media.
12. shadow (BoxShadow, BoxShadowColour, BoxShadowColourHover; hover colour disabled until a shadow is set). Mounted: media, hero splitMedia.
13. media-padding (Padding, a per-device 4-side box). Mounted: media, hero splitMedia.
14. caption (Caption, CaptionTag). Mounted: sgs/media only.
15. link (LinkUrl, LinkOpensNewTab, LinkRel, LinkUrlSource). Mounted: sgs/media only.

Atom census facts to keep straight: sgs/media adopts all 15; hero splitMedia adopts 7; 21 other surfaces adopt only object-fit (and sometimes focal-point). No atom exists for: hover zoom, filter and colour treatment, duotone, blend on the media itself, parallax, Ken Burns, picture and art direction, preload, poster as its own atom (Thumbnail and ThumbnailId live inside source), mask or SVG shape. Registry comment says absence on a surface is a gap, not a decision; the gaps are measured in reports/migrations/media-element-census.json.

## 4. Real gaps (searched and not found)
1. A shape or mask system beyond four clip-path presets: no blob, arch, organic or custom SVG mask, no per-device shape, no mask-image on photos or video, no library.
2. A shaped box loses its box-shadow and border-outside to the clip; a filter-based drop-shadow path exists (helpers-shadow-filter.php) but is not wired to the shape.
3. Atom adoption: 21 surfaces get only object-fit; the decorative-image, team-member, gallery, card-grid and product-card have no box-shape, overlay, shape or ratio from the atom (each hand-rolls its own).
4. No `<picture>` and no preload emitter; art direction is element-per-tier toggled by CSS (hidden elements still download unless handled, see helpers-tier-media.php comment on preload=none).
5. No deleted-attachment state in editor or render.
6. No chip-style ratio picker, no "use the image's own ratio" choice.
7. No hover-zoom, filter, duotone, Ken Burns or parallax atom (each is per-block).
8. No generic ConditionalControl or ToolsPanel host: disclosure lives inside each atom's logic module.
9. Poster images ignore srcset and cover-crop.
