## 3. What `sgs/media` can reach today versus `sgs/decorative-image`

Evidence: `generated-fx-qualifying-blocks.json` has no `sgs/media` key; `sgs/decorative-image` lists 15 effects. `plugins/sgs-blocks/src/blocks/decorative-image/block.json::supports.sgs.fx.motionSurface` is true; `plugins/sgs-blocks/src/blocks/media/block.json` has no `motionSurface` (grep `motionSurface` over `src/blocks/*/block.json` returns decorative-image only). `src/blocks/extensions/motion/effect-options.js` keeps an effect only when the block qualifies for it. `sgs/media` has `supports.sgs.motion: true`, parts `media` (`motionSelector` `.sgs-media-el`) and `caption` in `motion_targets`.

1. 3. Looping SVG: `svg-loop` effect (`fx-svg-loop.js`) versus the media SVG presentation atom (`includes/media/atoms/svg-presentation.php`); the keyframes `sgs-media-svg-pulse/float/wave` are defined in both `assets/css/media-element.css` and `assets/css/media-atoms/svg-presentation.css`. 4. Parallax: `fx-parallax.js` versus Background panel "Fixed (parallax)" (`background-attachment: fixed`) versus scrub's `background-position` row (the registry refuses the last pair with parallax).
5. Fade on scroll: `decorative-image/view.js` own rAF loop versus `scrub` opacity.
6. Scroll progress: `fx-scroll-progress.js` versus `timeline/view.js::initProgressDriver`.
7. Carousels: `fx-carousel-loop.js`, `fx-marquee.js`, `testimonial-slider/view.js`, `google-reviews/view.js`, `trustpilot-reviews/view.js`, `post-grid/view.js` are six runtimes; Spec 38A Appendix A says carousel-loop "is not a marquee".
8. Magnet: `magnet.js` plus `fx-magnet.js` versus `label-magnet.js`; Spec 38A Appendix A says the label magnet's constants become stamped values (not verified done).
9. Smooth scroll: Lenis `src/shared/effects/smooth-scroll.js` versus `theme/sgs-theme/assets/js/smooth-scroll.js` (the latter inert, see section 1).
10. Cursor spotlight: `spotlight.js` is a retained shim over `cursor-field.js` (its header says add nothing there).
11. Ripple, sheen and glare each need a pseudo-element or injected span, so none of them reaches a bare `<img>`, `<video>` or `<iframe>` without a wrapper (reading, not tested).
