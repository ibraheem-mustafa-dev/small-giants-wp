# A4: platform docs check for Spec 49 (v0.5, uncommitted)

Date 2026-11-09. Target platform WordPress 7.1 (canary runs it). Nothing was run; every row cites the document it came from, or says "not verified". A1, A2 and A3 findings are not repeated (sizes `auto` prefix, minimum lead-image area, Cover pattern, Motion's native-first driver, `renderIn`, Gutenberg dimension precedence).

## What Context7 covered

Covered, with library ids: `/wordpress/gutenberg` (block supports, theme.json responsive styles and `viewport`, bindings, Interactivity directives, `block.json`, `useSettings`), `/wordpress/wordpress-develop` (`wp_get_attachment_image` and `auto, ` sizes), `/websites/gsap` (`gsap.matchMedia`), `/microsoft/playwright/v1.64.1` (`Screencast.start`, `Mouse.wheel`). Not covered (WebFetch or WebSearch used instead, named in each row): WordPress 7.0 and 7.1 dev notes and Gutenberg Times source of truth, MDN, web-platform baseline data (`api.webstatus.dev`), the developer.wordpress.org component pages and `WP_Block_Type`. Context7 timed out or reset on three calls (first Playwright resolve, MDN resolve, two Gutenberg queries); the retries worked except MDN, which has no Context7 library here. It never returned `dimensions.aspectRatios` settings or any `ScrollTimeline` guidance.
