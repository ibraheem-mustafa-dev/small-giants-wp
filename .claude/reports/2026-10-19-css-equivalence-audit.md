# CSS properties the drafts use that Fill does not read: what SGS already does with each

Date: 2026-10-19. Scope: the 86 CSS properties the Indus Foods and Mama's Munches redesign drafts use that `scripts/computed-route/lib/fill-read.mjs::PROPS` does not read, matched by what each does on the page (not by property name) against the framework DB, the blocks' default stylesheets, settings under other names, the motion model and the theme. Three read-only audits; five citations spot-checked against the files (the container sideways-scroll CSS in `plugins/sgs-blocks/includes/container-scroll-row-css.php`, `cursor: pointer` in `plugins/sgs-blocks/src/blocks/button/style.css`, round caps on all 1,917 paths in `plugins/sgs-blocks/includes/lucide-icons.php`, the Mama's `accent-color: #EE8088` against its snapshot primary `#a8404f`, and no `-webkit-text-stroke` rule anywhere in SGS). Governing work: Spec 48 FR-48-8 and FR-48-85, plan `.claude/plans/2026-10-19-fr48-8-declared-values.md`.

Verdicts: setting 25, block-default 21, not-needed 21, motion 6, missing 5, partial 5, theme 3. A property can split by occurrence; the note gives the split.

## Real control gaps

Twelve features the drafts use that no SGS control, block default, theme rule or composition of existing blocks reproduces. Each passed five tests: what the draft really does, the block that would hold it, whether it is already built, whether existing blocks compose it, and whether a universal fix serves better. Per-block custom CSS and a heading split into several blocks are not counted as answers. The build plan is .claude/plans/2026-10-19-control-gaps-build.md.
