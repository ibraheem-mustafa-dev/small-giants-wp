# D643 — colour-attribute CSS-property classification (derived from render code)

**2026-08-16.** Derived by three parallel agents READING the actual render code for every
`role='color'` sgs attribute that carried a NULL `css_property` (54 of them). Not inferred from
attribute names — an automated name/grep probe was tried three times and resolved only 13 of 54,
and on `sgs/product-card.tagBackgroundColour` it returned `color`, which is WRONG.

⚠ **This research is NOT applied to `attr-classification-overrides.json`.** Applying `css_property`
alone produced **51 new F6 violations**: `cssprop:undeclared-subelement`. The gate's own fix text is
explicit — *"Declare the element in the block's `supports.sgs.elements.<el>.attrMap`, NOT an
attr-classification override"*. A property with no `css_element`/`derived_selector` falls to the
root routing domain and **would misroute on a clone**. The follow-up must declare the ELEMENT per
block, using the table below as its input.
